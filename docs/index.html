Behind the experience

From voice to conversation.

The repository contains Python modules for a local prototype. This public page demonstrates the concept without running those modules.

01 / CAPTURE

Voice input

A local microphone recording can provide audio for processing.

02 / INTERPRET

Speech + audio features

Speech recognition transcribes words; MFCC features feed the emotion model.

03 / RESPOND

Response + speech

The intended flow generates a reply and converts text into spoken audio.

04 / REMEMBER

Local history

The Python prototype includes SQLite storage for conversation history.
